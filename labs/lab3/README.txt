Lab 3: User Login and Registration System


Author: Zephaniah Chizulu
Date: October 30, 2025

Description:
Simple user login and registration system with form validation and visual feedback.

Implementation Details:
- **ES6 Features**: Arrow functions, destructuring, Maps/Sets, error handling (try-catch).
- **Data Storage**: Map for users (key-value), Set for username checks.
- **Validation**: Custom loops for email, username, password (bonus: no built-ins like regex.test()).
- **DOM**: Event listeners for submit/blur, style.display for errors, classList for borders.

Maps and Sets Usage:
- **Map**: Efficient key-value storage for credentials (O(1) get/set).
- **Set**: Fast existence checks for usernames (O(1) has).

How to Run/Test:
Open index.html (registration) or login.html (login) in browser. Test inputs and check console.
